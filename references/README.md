# Model references

- Henault and Guimond, *Orbit determination of a LEO satellite with passive RF*,
  Advances in Space Research 75 (2025), especially equations (1)–(3).
  [Publisher search](https://www.sciencedirect.com/search?qs=Orbit%20determination%20of%20a%20LEO%20satellite%20with%20passive%20RF).
- *One-way Doppler and Interferometry: Space Domain Awareness* (2022), for the
  corresponding phase/path-length relation.
  [Publisher search](https://ieeexplore.ieee.org/search/searchresult.jsp?queryText=One-way%20Doppler%20and%20Interferometry%20Space%20Domain%20Awareness).

Supplied PDFs remain locally in this directory, ignored by Git and excluded
from the Cargo package. The phase and differential measurement guides document
which models are implemented and their numerical assumptions.
